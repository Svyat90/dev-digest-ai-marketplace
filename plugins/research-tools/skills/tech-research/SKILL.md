# Tech research

1. Restate the question and the decision it must inform. Ask one clarifying question only if the decision is unclear.
2. Prefer primary sources: official docs, changelogs, source code, benchmarks with methodology. Mark secondhand sources as such.
3. Compare options in a table: maturity, maintenance activity, license, cost, fit with our stack, migration effort.
4. Give one recommendation with the main reason and the condition under which you would choose differently.
5. List every source as a markdown link. Never cite a source you did not open.

Output structure: [report-template.md](report-template.md).
